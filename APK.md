# Gerar o APK (Capacitor)
O site continua sendo HTML/CSS/JS puro. Node só é usado por você, no seu computador, para empacotar.
1. `npm install`
2. `npx cap add android`
3. `npm run sync`
4. `npx cap open android` e, no Android Studio: Build > Build APK.
Os vídeos dentro do APK aumentam muito o tamanho; prefira vídeos hospedados online.
